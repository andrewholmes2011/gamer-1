# Pulse Arena

A browser-based 3D first-person arcade arena built with HTML, CSS, JavaScript, and Three.js.

## Play locally
Open `index.html` in a modern browser with an internet connection. Three.js is loaded from jsDelivr.

## Controls
- **WASD / Arrow keys:** Move
- **Mouse:** Look around (click **Enter Arena** first)
- **Left click:** Send a pulse to tag a practice drone
- **Esc:** Pause / release the mouse

## Features
- 3D arena with neon lighting, grid floor, and obstacles
- First-person mouse-look and movement
- Roaming practice drones and pulse-tag scoring
- 60-second round, energy meter, and responsive HUD

## Publish with GitHub Pages
In the repository settings, open **Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. After deployment, GitHub will display the public site URL in Pages settings.

Three.js is an open-source 3D library. This project loads its browser module from jsDelivr.
